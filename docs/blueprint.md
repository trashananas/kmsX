# **App Name**: Polochka Exchange

## Core Features:

- User Authentication: Secure user registration and login functionality for personalized access.
- Item Listing and Browsing: Users can create new item listings for exchange, and browse existing items with basic filtering capabilities.
- Category Management: Display a comprehensive list of item categories and enable filtering of items by selected categories.
- Location-aware Item Display: Integrate geocoding (e.g., Yandex Maps API) to allow users to specify item locations and enable searching/displaying items based on proximity.
- 'Swipe' Mode UI: Implement an alternative, dynamic viewing mode for items with a 'swipe-like' interaction for quick discovery, inspired by Tinder/TikTok feeds.
- Firestore Integration: Utilize Firestore as the backend database for storing and managing user data, item listings, and categories efficiently.

## Style Guidelines:

- Primary color: Muted Blue (#617EA3) to convey trust and a modern, organized aesthetic for interactive elements.
- Background color: Very light Blue-Gray (#F1F5F8) for a clean, open, and serene canvas that complements the primary color.
- Accent color: Bright Aqua (#4CD9D9) to draw attention to call-to-action buttons, key highlights, and active states, providing a fresh contrast.
- Body and headline font: 'Inter' (sans-serif) for its modern, highly legible, and objective characteristics, suitable for various content lengths.
- Use clear, minimalistic, and outlined icons that are intuitive and consistent with a modern design, supporting item actions and navigation.
- Adopt a card-based layout for item listings, supporting responsive design across devices, with organized modals for detailed interactions.
- Subtle and smooth animations, particularly for 'swipe' interactions, modal transitions, and filtering changes, enhancing user engagement and fluidity.
